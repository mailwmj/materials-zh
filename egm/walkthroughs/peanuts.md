# Peanuts 演练

> **Bootstrapping（"peanuts 和 hay"）**

`peanuts` 是 EGM 方法的起点。它构建一个自底向上的 README 文件树，作为 Elephant 设计的输入。

## 它做什么

在大型遗留代码库中，AI 智能体无法一开始就理解整个系统。上下文窗口有限，而代码库可能很大。`peanuts` 通过让智能体从叶子目录开始构建 README 文件来解决这个问题，然后逐步向上合并到更高级别的目录中。

这类似于人类如何学习一个新代码库：你先了解一个小组件，然后了解它如何融入模块，再了解模块如何构成系统。每一步都有一个人工审查关卡，确保智能体在继续之前正确理解了每个部分。

## 何时使用

- 当你有一个大型遗留代码库，且 AI 智能体需要理解它时
- 在开始任何设计或实现工作之前
- 当代码库缺乏文档，且你需要一个结构化概述时

## 执行步骤

### 步骤 1：找到叶子目录

智能体从代码库的叶子目录开始（没有子目录的目录）。对于每个叶子目录：

1. 读取目录中的所有文件
2. 编写一个 `README.md`，描述：
   - 此目录的用途
   - 主要文件及其作用
   - 关键函数、类或组件
   - 与其他目录的关系
3. 将 README 保存到 `README.md`

### 步骤 2：人工审查

在每个叶子 README 之后，人类审查智能体的工作。检查：

- README 是否准确描述了代码？
- 关键组件是否被识别？
- 语言是否清晰且适合其他智能体阅读？

如果 README 不准确，与智能体讨论并修复它。不要继续，直到此 README 可靠。

### 步骤 3：合并到父目录

一旦叶子 README 可靠，智能体就向上移动到父目录。对于父目录：

1. 读取所有子目录的 README
2. 读取父目录中的文件
3. 编写一个 `README.md`，描述：
   - 此目录的用途
   - 子目录及其作用
   - 父目录中的主要文件
   - 此目录如何适合更大的系统
4. 将 README 保存到 `README.md`

### 步骤 4：人工审查

再次审查父 README。检查子 README 是否被准确概括，以及父 README 是否提供了正确的更高层次视图。

### 步骤 5：重复直到根目录

重复步骤 3 和 4，直到你到达代码库的根目录。最终输出是根目录中的一个 `README.md`，它概括了整个系统。

## 输出

- `README.md` — 每个目录中
- `PEANUTS.md` — 根目录中的账本文件，记录哪些目录已完成、审查决策以及任何未解决的问题

## 与 Elephant 的接口

`peanuts` 的输出是 `elephant` 的输入。当 Elephant 技能启动时，它读取根 `README.md` 以了解系统架构，然后开始设计对话。

这就是为什么人工审查关卡至关重要：如果 README 不准确，Elephant 将从错误的假设开始。

## 提示词

`peanuts` 使用 `peanuts` 提示词来指导智能体构建 README 文件。提示词告诉智能体：

- 如何识别叶子目录
- 如何编写 README
- 何时暂停进行人工审查
- 如何向上合并到父目录

如果 Python 不可用，智能体可以手动执行相同操作：使用 `git ls-files` 列出目录，从最深到最浅排序，然后在汇总之前检查每个父目录的子目录。

## 示例

假设你有一个代码库，结构如下：

```
src/
├── auth/
│   ├── login.py
│   └── logout.py
├── api/
│   ├── users.py
│   └── posts.py
└── main.py
```

`peanuts` 会：

1. 从 `auth/` 和 `api/` 开始（叶子目录）
2. 为每个目录编写 README
3. 等待人工审查
4. 合并到 `src/`
5. 为 `src/` 编写 README
6. 等待人工审查
7. 合并到根目录

最终输出：

```
src/
├── README.md
├── auth/
│   ├── README.md
│   ├── login.py
│   └── logout.py
├── api/
│   ├── README.md
│   ├── users.py
│   └── posts.py
└── main.py
README.md
```

## 限制

- `peanuts` 只创建 README 文件。它不设计功能、不审查代码、不实施更改。
- 人工审查关卡是强制的。不要跳过它们。
- README 质量取决于智能体对代码的理解。如果代码混乱，README 也会混乱。
