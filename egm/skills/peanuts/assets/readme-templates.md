# README 模板

此文件包含 peanuts 技能用于生成 README 文件的模板。

## 目录 README 模板

```markdown
# <目录名>

<目录用途的简短描述。>

## 文件

| 文件 | 用途 |
|------|------|
| `<文件名>` | <文件做什么的简短描述> |

## 关键组件

### <组件名>

<此组件的描述。>

- **类型**: <类型：函数、类、模块等>
- **用途**: <它为什么存在>
- **关系**: <它与其他组件的关系>

## 备注

<其他可能对理解此目录有用的任何信息。>
```
