# notes：L01 演示

L01 实时演示运行的小代码库。`notes.py` 是一个六十行的笔记
CLI，有两个故意缺陷，演示在三个提示中修复两者，没有人输入一行代码。

你有这个，所以你可以自己运行它。观看某人驾驶 aider 和
驾驶它是不同的技能，只有一个是考试的内容。

## 获取工作副本

```sh
./reset
```

这在你的克隆根目录旁边构建一个一次性副本在 `demo-scratch/L01-notes-cli`，
设置 aider 的配置，使其成为一个 git 仓库，所以 `/undo` 有效，
并运行测试。它在完成时打印完整路径，所以你永远不必计算它。随时再次
运行它以重新开始。不要在这个目录中运行 aider：这里的配置文件是故意
不加点的（`aider.conf.yml`，不是 `.aider.conf.yml`），以便 aider
忽略它们，这个副本保持原始。

然后：

```sh
cd ../../demo-scratch/L01-notes-cli
aider notes.py test_notes.py
```

`./reset --model 4b` 固定 4B 代替，值得做一次。见下文。

## 两个缺陷

在你开始之前打开 `notes.py`。它很短是故意的。

- **`parse_args()` 在没有参数时崩溃。** 空列表上的 `argv[0]` 是
  `IndexError`。运行 `python3 notes.py` 并观看它崩溃。
- **`dispatch()` 是一个 if 链。** 它工作。它只是不是你会写的方式。

测试无论如何都通过，全部四个，这是第一个值得注意的事情：绿色的
套件与好的代码不是一回事。

## 三个提示

逐字说出它们。它们是演示。

1. `Refactor parse_args() to handle the no-args case — print usage and exit cleanly.`
2. `Add a unit test for the no-args path.`
3. `Replace the if-chain in dispatch() with a dictionary lookup.`

每一个之后，**在接受它之前阅读 diff**。这是练习的全部要点。模型
生成；你判断。在你可以看到的地方运行套件：

```
/run pytest -q
```

提示 2 之前四个测试，之后五个，提示 3 之后仍然绿色。

## 实际要注意什么

不是命令。`aider-practice` 教授命令，它教得比五分钟演示更好。

注意循环：你描述一个结果，模型提出一个更改，你阅读它并决定。五
分钟内三个协调编辑，零行输入是协作的形状，判断步骤仍然是你的部分。

## 在 4B 上尝试

```sh
./reset --model 4b
```

同样的三个提示，更小的模型。预期更努力地工作：更多反馈回合，以及
至少一个你应该拒绝的 diff。那不是缺陷，那是课程更快到达。问题从来
不是"这个模型是否坏。"它是上下文、模型或提示，这是 L03。

## 配置

`aider.conf.yml` 为主模型和弱模型都固定 9B，所以 Ollama
持有一个模型，而不是在每个自动提交时交换。

它还设置 `think: false`。qwen3.5 是一个推理模型，如果放任不管，
在写任何代码之前花费其预算思考：在这个项目上测量，1200 token 推理
和零字符输出，23 秒 against 9。如果你的提示需要 25 秒或更多，参数
没有到达 Ollama；在每个提示末尾添加 ` /no_think` 代替。

`aider.model.metadata.json` 故意将这些免费本地模型的价格定在 frontier
价格，所以 `/tokens` 回答"如果我付费，这个会话会花费什么。"

## 提示 1 要观察的内容

提示 1 在 9B 上大约一半时间工作。十次运行，三次修复，以及切换 aider
的编辑格式 barely moves it。

它不以同样的方式失败两次，所以不要记忆一个签名。在排练中看到的两种
形状：模型写了一个修正的 `parse_args()` 并在下面的文件中留下原来的，
所以 Python 绑定第二个定义，什么也没有改变；或者它写了一个 no-args
分支，返回 `main()` 无法解包的东西，每个命令都坏了。

这里是你应该 bother 的部分。这两种形状对测试套件看起来完全不同。
第一个在二十次运行中让所有四个测试保持绿色，因为没有现有测试用
空列表调用 `parse_args`。第二个立即将套件变红。

所以提示 1 后的绿色套件告诉你关于提示 1 是否工作的任何事情。运行
`python3 notes.py`——提示是关于的东西——并在接受它之前阅读 diff。
注意到这是这里的实际技能，以及为什么给你代码库而不是视频。
